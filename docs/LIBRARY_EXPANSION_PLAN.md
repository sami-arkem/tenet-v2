# Library Expansion Plan

## Goal
Turn Tenet into a reusable deterministic audit engine across:
- AML
- KYC / KYB
- sanctions
- governance
- vendor / third-party risk

## Principles
- deterministic only
- stable control IDs
- human-readable controls
- reusable regime packs
- reusable audit-type mappings
- no fake model logic

## Outputs
- control library
- regime library
- audit type to control mapping
- audit type to regime mapping
- tests for non-empty coverage
