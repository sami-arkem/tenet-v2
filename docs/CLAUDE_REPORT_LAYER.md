# Claude Report Layer

## Rule
Claude does not decide audit logic.
Claude transforms locked audit JSON into premium reports.

## Inputs
- locked audit output JSON
- report pack
- report prompt contract

## Outputs
- board memo
- regulator memo
- client report markdown

## Non-negotiables
- no change to deployment decision
- no change to control assessment
- no invented evidence
- no invented findings
- no invented controls

## Tone
- boardroom ready
- regulator ready
- premium advisory
