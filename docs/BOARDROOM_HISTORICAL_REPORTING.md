# Boardroom Historical Reporting

## Goal
Expose deterministic historical and trend context in Tenet's report pack so board and regulator outputs can reference repeated weaknesses and remediation direction without altering current audit truth.

## Non-negotiables
- historical context is advisory only
- current deployment decision remains authoritative
- current findings remain authoritative
- current missing controls remain authoritative
- no model dependency required for this layer
- all historical fields must be clearly labeled as prior/historical context

## Historical context fields
- prior recurring missing controls
- prior recurring findings
- prior decision trajectory
- prior remediation trajectory
- repeated governance weaknesses
- repeated screening weaknesses
- repeated licensing weaknesses
- repeated remediation weaknesses

## Reporting rule
Historical context may enrich:
- board memo
- regulator memo
- client report appendix / context sections

Historical context may not:
- change decision
- change severity
- change current findings
- change current missing controls
