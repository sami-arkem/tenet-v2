# Main Flow Future-Pack Hardening

## Goal
Make future-pack audit types first-class citizens across:
- deterministic reasoning
- pack-composed retrieval prep
- report generation
- report validation
- export packaging

## Scope
This hardening layer covers:
- fraud_readiness_review
- transaction_screening_review
- regulatory_licensing_readiness_review
- remediation_tracking_review

## Non-negotiables
- deterministic audit core stays authoritative
- no model dependency for this hardening layer
- pack-composed controls and regimes must appear in runtime preparation
- report/export path must work against at least one future-pack case
- py_compile and pytest must stay green
