# Real Gold Cases Only

This directory is intentionally empty until populated with real adjudicated audit cases.

Do not add:
- synthetic examples
- guessed expected outcomes
- placeholder evidence manifests
- mock client cases

Each subdirectory must contain:
- audit_context.json
- expected_assertions.json
- case_notes.md

Add cases only after:
1. the relevant evidence corpus is available to the active retrieval layer
2. a human reviewer has adjudicated the expected outcome
3. the expected assertions are defensible in a real audit review
